# นโยบายความปลอดภัยไอที — บริษัท ตัวอย่าง จำกัด (เอกสารสมมติสำหรับแล็บ)

## รหัสผ่าน
- รหัสผ่านต้องยาวอย่างน้อย 12 ตัวอักษร และมีทั้งตัวอักษรและตัวเลข
- ห้ามใช้รหัสผ่านซ้ำกับบริการภายนอก
- ทุกระบบที่รองรับต้องเปิดใช้การยืนยันตัวตนสองชั้น (MFA)

## อุปกรณ์
- โน้ตบุ๊กของบริษัทต้องเข้ารหัสดิสก์ และล็อกหน้าจออัตโนมัติภายใน 5 นาที
- ถ้าอุปกรณ์สูญหายหรือถูกขโมย ต้องแจ้งทีม Security ที่ security@example.com ภายใน 1 ชั่วโมง

## ข้อมูล
- ห้ามนำข้อมูลลูกค้าไปใส่ในบริการ AI สาธารณะที่บริษัทไม่ได้อนุมัติ
- ไฟล์ที่ระบุว่า "ลับ" ต้องเก็บไว้ในไดรฟ์ขององค์กรเท่านั้น
